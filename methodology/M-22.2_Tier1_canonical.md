## §1 Pattern Statement

**M-22.2 Tier 1 wrapper-layer absorption pattern:** a wrapper theorem composing prior `[propext]`-only theorems via direct anonymous-constructor (`⟨α, β, γ, …⟩`) or simple aliasing inherits the underlying `[propext]`-only axiom record without introducing additional axioms.

The pattern's load-bearing property: the composition mechanism is *axiom-record-preserving*. No new tactics, no `Classical.choice`, no `Quot.sound`, no project axioms — the composed theorem's machine-checked axiom record matches the union of its component theorems' axiom records (which under the Tier 1 hypothesis is `[propext]`-only).

CI gating enforces the property at every push/PR to main via `#print axioms` direct query against the composed theorem name + grep-and-fail assertion against `depends on axioms: [propext]`.

## §4 Operational Guidance for Future Proof Work

**When to apply M-22.2 Tier 1 wrapper-layer absorption:**

- Target theorem is composable from prior-layer theorems already proven at `[propext]`-only.
- Wrapper structure is direct anonymous-constructor (`⟨_, _, …⟩`), simple aliasing (`:= prior_theorem_name`), or `simp [definition]`-based reduction without introducing tactics that surface additional axiom dependencies.
- M-26.1 compose-from-outside discipline applies at the wrapper-layer boundary (no modifications to prior-layer source files; cross-references additive-from-outside only).

**Pattern signature:**

```lean
theorem wrapper_theorem :
    [composed proposition] :=
  ⟨prior_theorem_α, prior_theorem_β, ...⟩
```

OR

```lean
theorem wrapper_alias :
    [restatement of prior theorem at composition layer] :=
  prior_theorem_name
```

**Axiom record target:** `[propext]`-only. CI gating via `#print axioms` direct query + grep-and-fail assertion in build.yml under per-layer parallel CI block.

**Avoid tactics that may surface additional axiom dependencies:** `Classical.choice`-dependent tactics (e.g., classical case analysis without explicit decidability); `Quot.sound`-dependent tactics (e.g., quotient reasoning); arbitrary `decide` tactic application (can surface `Classical.choice` via implicit decidability).

## §5 Audit-Gate CI Pattern

Per-layer parallel CI blocks at `.github/workflows/build.yml` enforce axiom-record preservation:

```yaml
- name: Verify Layer 6-X theorem axiom records
  run: |
    set -euo pipefail
    output=$(lake env lean QanaryContracts/PrintAxioms.lean 2>&1 | awk '
      /^'\''/ { if (acc != "") print acc; acc = $0; next }
      acc != "" && /^ / { sub(/^[ ]+/, " ", $0); acc = acc $0; next }
      { if (acc != "") { print acc; acc = "" } ; print }
      END { if (acc != "") print acc }
    ')
    fail=0
    propext_only_theorems=(
      "QanaryContracts.theorem_name_1"
      "QanaryContracts.theorem_name_2"
      ...
    )
    for thm in "${propext_only_theorems[@]}"; do
      line=$(echo "$output" | grep -E "^'${thm}' " || true)
      if [ -z "$line" ]; then echo "::error::theorem ${thm} not found"; fail=1; continue; fi
      echo "$line"
      if ! echo "$line" | grep -qF "depends on axioms: [propext]"; then
        echo "::error::${thm} axiom set differs from expected ([propext]-only)"
        fail=1
      fi
    done
    if [ "$fail" -ne 0 ]; then exit 1; fi
    echo "PASS: ..."
```
